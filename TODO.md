## Android Sleep / Doze Mode

**Проблема**: При отключении экрана Android (Doze mode) убивает TCP-соединение на уровне ОС.
При включении экрана приложение пытается читать из мёртвого сокета → `Software caused connection abort`.
Автореконнект срабатывает (~4 сек), но соединение прерывается.

**Наблюдалось**: 2026-04-11 12:44 (Астана), клиент 802, IP 188.235.208.161.
Телефон спал с 13:52 до 14:44 (~52 минуты).

**Варианты решения** (в порядке предпочтительности):
- [ ] `PARTIAL_WAKE_LOCK` — удерживать сеть во время сна (затратно по батарее)
- [ ] `JobScheduler` / `WorkManager` с `setRequiredNetworkType(CONNECTED)` для поддержания соединения в фоне
- [ ] Принять текущее поведение — автореконнект за ~4 сек уже есть, можно просто ускорить обнаружение разрыва
